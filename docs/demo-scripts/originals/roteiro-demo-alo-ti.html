DEMO 01 · ROTEIRO DE PALCO

Alô, TI — OpenAI ao vivo

GPT-Live + Decisions API. Um chamado fictício nasce da voz, é reanalisado após correção e só vira ticket com confirmação humana.

7 minutos de palcoPT-BRUso local + API realPlano B incluído

Esta demonstração usa a aba OpenAI ao vivo da aplicação. Não é o laboratório de Codex CLI com /voice. Todos os textos da demonstração são fictícios. O modo palco destaca as falas e passos; o modo completo inclui a instalação e troubleshooting.

03

Como instalar e replicar em outra máquina

A preparação abaixo pode ser repetida em outra máquina. Se o Alô, TI já funciona em localhost:3000 e a API está configurada, pule diretamente para roteiro de palco.

Antes de ir ao palco: este fluxo já foi exercitado: relato → reanálise → ticket → pedido não autorizado recusado. Só inicie outra sessão se a anterior estiver efetivamente encerrada.
  1. Obtenha o código. Repositório público: https://github.com/glaucia86/devday-exchange-community-rio-2026. Para baixar, clone a branch main ou use Download ZIP. Você não precisa clonar novamente se já está com a página local aberta.
  2. Confirme o Node.js. Abra PowerShell na pasta apps/decisions e confira node --version. O projeto aceita versões 24.12.0–24.21.0.
  3. Instale, construa e sirva. Se for uma instalação inicial, execute os comandos PowerShell abaixo. Se já funciona, não reinstale durante o palco.
  4. Configure a API de forma privada. Pare o servidor com Ctrl+C; preserve qualquer .env.local existente. Crie só se não existir, confirme que o Git o ignora e edite-o no bloco de notas.
  5. Preencha os segredos somente na máquina. MESA_LIVE_ENABLED=true, OPENAI_API_KEY com a chave autorizada e MESA_LIVE_ACCESS_TOKEN com o código local aleatório. Não coloque NEXT_PUBLIC_ nas variáveis.
  6. Reinicie o Next.js. Execute npm.cmd run build e npm.cmd start na pasta apps/decisions. Abra uma única aba no endereço local do roteiro.
  7. Autorize uma sessão real conscientemente. Confira projeto da API, limites, faturamento e consentimento. A assinatura ChatGPT não cobre automaticamente o consumo da API.

Primeira instalação (PowerShell)

Pasta raiz → apps/decisions
git clone --branch main https://github.com/glaucia86/devday-exchange-community-rio-2026.git
cd devday-exchange-community-rio-2026
cd apps/decisions
node --version
npm.cmd ci --ignore-scripts
npm.cmd run build
npm.cmd start

Ativar uma API já autorizada

Sem imprimir segredos no terminal
# No PowerShell, em apps/decisions, com o servidor parado:
if (-not (Test-Path .env.local)) { Copy-Item .env.example .env.local }
git check-ignore -v .env.local
node -e "console.log(require('node:crypto').randomBytes(24).toString('base64url'))"
notepad .env.local

Se a porta 3000 estiver ocupada, confirme que não há outro servidor; use npm.cmd start -- -p 3002 quando apropriado.

04

Plano B e imprevistos

Se algo falhar, apresente com transparência o que realmente foi executado e evite gastar minutos tentando resolver no palco.

Falha de voz

Se a função não for executada

Observe o log Comandos da voz e o estado na tela. Se só a delegação de analisar falhar, use o botão Analisar com Decisions e explique o fallback.

Sem áudio/microfone, encerre a conversa e prossiga com o modo Simulado, rotulando-o claramente como simulação.

Falha da API

Fluxo offline que não depende da API

Na aba Simulado: Explorar cenário → Analisar relato → Simular uma correção → Analisar relato → revisar → confirmar o ticket simulado. A voz local opcional do navegador não é GPT-Live.

Como conferência sem custo: node scripts/replay-voice-commands.mts (em apps/decisions).

05

Notas técnicas e materiais

O que afirmar com precisão

Arquitetura: a página usa áudio por WebRTC com GPT-Live, enquanto a análise consulta a Decisions API no servidor. As ações autorizadas são registrar, corrigir, analisar, confirmar ticket e recomeçar.

O que esta demo não é: não existe integração com sistema real de chamados nem permissão para apagar dados ou recuperar segredos. O ticket DEMO-0001 é fictício.

Encerramento: aguarde a confirmação “Conversa encerrada. Microfone liberado.”. O limite local de 10 minutos não equivale a um limite de gastos da API.
