03

Como instalar e replicar em outra máquina

A preparação abaixo pode ser repetida em outra máquina. Se o Alô, TI já funciona em localhost:3000 e a API está configurada, pule diretamente para roteiro de palco.

Antes de ir ao palco: se houver cartão salvo, confira o estado. Para uma rodada limpa, encerre a sessão anterior, confirme o fechamento e só depois use Nova triagem. O quadro pode ser restaurado após recarregar.
  1. Obtenha o código. Repositório público: https://github.com/glaucia86/decisions-ai-demos. Para baixar, clone a branch main ou use Download ZIP. Você não precisa clonar novamente se já está com a página local aberta.
  2. Confirme o Node.js. Abra PowerShell na pasta raiz do repositório decisions-ai-demos e confira node --version. O projeto aceita versões 24.12.0–24.21.0.
  3. Instale, construa e sirva. Se for uma instalação inicial, execute os comandos PowerShell abaixo. Se já funciona, não reinstale durante o palco.
  4. Configure a API de forma privada. Pare o servidor com Ctrl+C; preserve qualquer .env.local existente. Crie só se não existir, confirme que o Git o ignora e edite-o no bloco de notas.
  5. Preencha os segredos somente na máquina. MESA_LIVE_ENABLED=false, OPENAI_API_KEY com a chave autorizada e MESA_LIVE_ACCESS_TOKEN com o código local aleatório. Não coloque NEXT_PUBLIC_ nas variáveis.
  6. Reinicie o Next.js. Execute npm.cmd run build e npm.cmd start na pasta raiz do repositório decisions-ai-demos. Abra uma única aba no endereço local do roteiro.
  7. Autorize uma sessão real conscientemente. Confira projeto da API, limites, faturamento e consentimento. A assinatura ChatGPT não cobre automaticamente o consumo da API.

Plano B e imprevistos

Se algo falhar, apresente com transparência o que realmente foi executado e evite gastar minutos tentando resolver no palco.

Problema de microfone/delegação

Se “Registra” não gerar cartão

Confira o texto em OUVINDO. Se estiver correto mas a delegação não ocorrer, clique em Classificar agora e avise à sala que acionou manualmente a classificação.

Se houver 429, veja Na fila; o relato ainda não virou cartão. Evite chamadas repetidas. Encerre a sessão e confirme o fechamento.

Problema de API / conexão

Não há simulado de Triagem neste fluxo

Feche a sessão, se ela foi iniciada. Mostre apenas uma gravação identificada como GRAVADO ANTES. Sem gravação, execute node --test tests/triage.test.mts em raiz do repositório decisions-ai-demos e explique a regra da revisão humana.

Não apresente um teste offline como classificação real via API.

05

Notas técnicas e materiais

O que afirmar com precisão

GPT-Live e Decisions são APIs distintas. A Triagem usa delegação custom/client e chamada Decisions pelo servidor; a aba ao vivo da Alô, TI usa delegação Responses. Esta aplicação não foi migrada para integração nativa Decisions.

Gatilho de classificação: ao falar “registra”, GPT-Live delega para a aplicação, que faz a chamada a Decisions. Normalmente há uma tentativa por relato; o contador também registra falhas e não é um extrato financeiro.

Revisão humana: contexto inferior a 0,8 ou confiança de equipe inferior a 0,7 conduzem ao fluxo de revisão, com valores didáticos, não calibrados para produção.

Limites: após fechar a sessão, verifique a plataforma. Se aparecer “Finalização da sessão não confirmada”, não abra outra imediatamente.
